# Misi Pancasila — Truth or Dare

Game pembelajaran berbasis HTML, CSS, dan JavaScript untuk Pendidikan Pancasila kelas VII SMP. Kartu disusun dari PDF "Kartu Permainan Truth or Dare Berjenjang (C2-C5) — Pendidikan Pancasila Kelas 7".

## Isi fitur
- 38 kartu Truth dan Dare berdasarkan materi sumber (C2, C3, C4, C5)
- Pengacakan kartu per level dan pilihan Truth/Dare
- Skor tim: berhasil +10, sebagian +5, lewati tanpa penalti
- Mode guru: urutan berjenjang, target poin, timer, mode proyektor
- Unduh rekap permainan ke CSV
- Desain responsif untuk laptop, tablet, dan ponsel

## Menjalankan lokal
Buka `index.html` di browser. Tidak memerlukan instalasi atau build.

## Deploy lewat GitHub lalu Vercel
1. Ekstrak ZIP ini di komputer.
2. Buat repository baru di GitHub, misalnya `misi-pancasila-truth-or-dare`.
3. Klik **Add file → Upload files**, unggah `index.html` dan `README.md`, lalu **Commit changes**.
4. Buka Vercel dan masuk menggunakan akun GitHub.
5. Klik **Add New → Project**, pilih repository yang baru dibuat.
6. Untuk proyek statis ini, biarkan Framework Preset sebagai **Other**. Build Command dan Output Directory dapat dikosongkan; jika diminta Output Directory, gunakan `.`.
7. Klik **Deploy**. Setelah selesai, Vercel memberikan URL publik seperti `nama-proyek.vercel.app`.
8. Setiap perubahan yang di-commit ke repository GitHub akan memicu deployment baru otomatis.

## Catatan pembelajaran
- Bagi siswa dalam kelompok 4–5 orang sesuai panduan pada PDF.
- Mulai dengan level C2/C3, lalu lanjutkan C4/C5.
- Guru memutuskan apakah jawaban/aksi memenuhi rubrik. Poin merupakan alat bantu, bukan penilaian otomatis.
- Tantangan harus aman, sopan, inklusif, dan tidak mempermalukan siswa.
