# Misi Pancasila — Truth or Dare

Game pembelajaran Pendidikan Pancasila kelas VII berbasis HTML, CSS, dan JavaScript.

## Fitur
- Halaman utama dengan gaya visual cerah dan ilustrasi emoji
- Pilih level C2, C3, C4, C5
- Mode Truth, Dare, atau Acak
- Panduan jawaban dan skor
- Timer, target skor, mode guru, fullscreen/proyektor
- Rekap skor dan ekspor CSV
- Desain responsif untuk laptop, tablet, dan smartphone

## Jalankan lokal
Buka `index.html` di browser. Tidak memerlukan instalasi atau build.

## Deploy ke Vercel
1. Unggah `index.html` dan `README.md` ke root repository GitHub.
2. Di Vercel, impor repository tersebut.
3. Framework Preset: `Other`
4. Root Directory: `./`
5. Build Command: kosongkan / nonaktifkan.
6. Output Directory: `.`
7. Klik Deploy.

Catatan: versi ini menggunakan JavaScript di browser; skor dan riwayat tidak tersimpan lintas sesi atau perangkat. Materi di dalam kode adalah contoh kartu pembelajaran dan dapat disesuaikan dengan dokumen ajar.
